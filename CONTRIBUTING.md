# Contributing to 19 JHR BN NCC Portal

Thank you for contributing to the SBU Company NCC Portal!

## Development Guidelines

1. **Branch Naming**: Use descriptive branch names like `feature/attendance-chart` or `fix/enrollment-validation`.
2. **Type Safety**: Maintain strict TypeScript compliance. Ensure `npm run lint` passes before pushing.
3. **UI/UX Consistency**: Follow Tailwind utility conventions and the existing dark-navy and military-gold color palette.
4. **Pull Requests**: Open a PR with a description of changes against the `main` branch.
